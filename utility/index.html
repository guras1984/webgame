사용 안내

KJ 도구함은 어떻게 시작하나요?

Windows 통합판 다운로드를 누르고 파일을 받은 뒤 KJ 도구함 통합판 설치.cmd를 실행하세요. 사용자 프로그램 폴더에 필요한 파일을 배치하고 바탕화면 바로가기를 만듭니다. Python을 별도로 설치하지 않습니다. macOS는 ZIP 전체를 압축 해제한 뒤 KJ Toolbox.app을 실행하세요.

Windows 통합판은 도구함·PDF 편집기·이미지 편집기·한글·오피스를 포함합니다. 앱에 표시되는 PC 코드로 발급받은 KJS2 통합 라이선스를 등록하면 모든 도구를 사용할 수 있습니다. 라이선스가 없으면 전체 기능이 잠기며, PC가 바뀌면 재발급이 필요합니다.

설치 등록용 레지스트리·서비스·자동실행 항목은 만들지 않습니다. 제거는 도구함 왼쪽 아래 삭제를 누르세요. 메모·설정·라이선스 데이터 보존이 기본입니다.

현재 Windows 배포 후보는 미서명판입니다. 실행 환경의 보안 정책이 허용해야 하며, 한글의 편집·저장 화면 검증은 남아 있습니다. PDF·이미지 편집기는 Acrobat·Photoshop 전체 기능과 동일한 제품은 아닙니다.

패치 다운로더는 어떻게 사용하나요?
  1. Windows 설치 프로그램을 실행해 설치합니다. 바탕화면 바로가기는 기본 선택되어 있습니다. macOS는 ZIP을 풀고 앱을 응용 프로그램 폴더로 옮깁니다.
  2. KJ Patch Downloader를 실행하면 앱 전용 창이 열립니다.
  3. 대상 서버, 기준일, 종료일을 선택하고 업데이트를 조회합니다.
  4. 업데이트를 선택하고 선택 항목 파일 확인을 누릅니다.
  5. 선행·권장 패치도 함께 다운로드 체크박스로 포함 여부를 정합니다.
  6. 저장 폴더를 정하고 다운로드합니다.

인터넷 연결이 필요하며 파일은 실행 중인 컴퓨터에 저장됩니다. 대상 서버의 설치 상태와 공식 KB 문서를 확인한 뒤 설치 순서를 결정하세요.

지원 환경과 확인된 테스트 범위가 궁금해요.

macOS 앱은 Apple Silicon용입니다. Windows 앱은 x64용입니다. KJ 도구함 Windows 통합판은 Windows 11에서 설치·업데이트·삭제·데이터 보존, 라이선스 검사와 오피스 편집·저장·재열기·PDF 출력을 확인했습니다. 한글 편집·저장 화면, Windows 10과 다른 실물 PC의 검증은 남아 있습니다.

macOS 앱은 로컬 서명 앱이며 Developer ID 공증은 포함되지 않아 처음 실행 시 보안 경고가 표시될 수 있습니다. 프로그램별 상세 조건은 사용 안내에서 확인할 수 있습니다.

오류가 생기거나 새 버전을 찾고 싶어요.

사용한 운영체제, 프로그램 이름·버전, 재현 순서와 오류 문구를 함께 남겨 주세요.

사용 안내

KJ 도구함은 어떻게 시작하나요?

ZIP 전체를 압축 해제한 뒤 Windows는 KJ Toolbox.exe, macOS는 KJ Toolbox.app을 실행하세요. Windows는 Runtime·App·Data 등 동봉 폴더가 함께 필요합니다.

분류와 도구를 고르고 파일을 추가한 뒤 결과를 저장할 폴더를 선택하세요. Windows 버전은 처음 실행한 시점부터 7일간 체험할 수 있으며, 이후 앱에 표시되는 PC 코드로 발급받은 인증 키를 입력합니다.

패치 다운로더는 어떻게 사용하나요?
  1. Windows 설치 프로그램을 실행해 설치합니다. 바탕화면 바로가기는 기본 선택되어 있습니다. macOS는 ZIP을 풀고 앱을 응용 프로그램 폴더로 옮깁니다.
  2. KJ Patch Downloader를 실행하면 앱 전용 창이 열립니다.
  3. 대상 서버, 기준일, 종료일을 선택하고 업데이트를 조회합니다.
  4. 업데이트를 선택하고 선택 항목 파일 확인을 누릅니다.
  5. 선행·권장 패치도 함께 다운로드 체크박스로 포함 여부를 정합니다.
  6. 저장 폴더를 정하고 다운로드합니다.

인터넷 연결이 필요하며 파일은 실행 중인 컴퓨터에 저장됩니다. 대상 서버의 설치 상태와 공식 KB 문서를 확인한 뒤 설치 순서를 결정하세요.

지원 환경과 확인된 테스트 범위가 궁금해요.

macOS 앱은 Apple Silicon용입니다. Windows 앱은 x64용 설치 프로그램으로 배포합니다. 실제 Windows 데스크톱 실행 여부는 GitHub Actions 빌드와 별도로 확인이 필요합니다.

macOS 앱은 로컬 서명 앱이며 Developer ID 공증은 포함되지 않아 처음 실행 시 보안 경고가 표시될 수 있습니다. 프로그램별 상세 조건은 사용 안내에서 확인할 수 있습니다.

오류가 생기거나 새 버전을 찾고 싶어요.

사용한 운영체제, 프로그램 이름·버전, 재현 순서와 오류 문구를 함께 남겨 주세요.

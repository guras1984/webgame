사용 안내

KJ TOOL 통합판은 어떻게 시작하나요?

사용 중인 운영체제의 통합판 하나만 다운로드하면 도구함·PDF·이미지·한글·오피스를 모두 사용할 수 있습니다.

Windows 통합판 다운로드를 누르고 파일을 받은 뒤 KJ 도구함 통합판 설치.cmd를 실행하세요. 사용자 프로그램 폴더에 필요한 파일을 배치하고 바탕화면 바로가기를 만듭니다. Python을 별도로 설치하지 않습니다.

macOS 통합판 다운로드를 눌러 DMG를 받은 뒤, DMG를 열고 KJ TOOL.app을 Applications(응용 프로그램)로 복사하세요. 도구함에서 PDF·이미지·한글·오피스를 실행할 수 있으며 Python이나 Xcode를 별도로 설치하지 않습니다.

Mac 통합판은 실행 전에 인증이 필요합니다. 기본은 PC 지정 방식으로, 인증창의 내 PC 코드를 복사해 발급자에게 전달하고 받은 KJS2 인증 키를 입력하세요. 별도로 공용 키를 받았다면 PC 코드 전달 없이 같은 인증창에 입력하면 됩니다.

Windows 통합판은 도구함·PDF 편집기·이미지 편집기·한글·오피스를 포함합니다. 첫 실행부터 7일간 전체 기능을 무료로 체험할 수 있습니다. 체험이 끝나면 앱에 표시되는 PC 코드로 KJS2 통합 라이선스를 발급받아 등록하세요. 통합 라이선스 하나로 모든 도구를 사용할 수 있으며, PC가 바뀌면 재발급이 필요합니다. 같은 PC에서 재설치해도 체험 기간은 다시 시작하지 않습니다.

설치 등록용 레지스트리·서비스·자동실행 항목은 만들지 않습니다. 제거는 도구함 왼쪽 아래 삭제를 누르세요. 메모·설정·라이선스 데이터 보존이 기본입니다.

현재 Windows 배포 후보는 미서명판입니다. 실행 환경의 보안 정책이 허용해야 합니다. 한글의 한국어 입력·HWP 저장·재열기를 확인했습니다. PDF·이미지 편집기는 Acrobat·Photoshop 전체 기능과 동일한 제품은 아닙니다.

패치 다운로더는 어떻게 사용하나요?
  1. Windows는 ZIP 전체를 압축 해제하고 KJ Patch Downloader.exe를 실행합니다. Runtime·App 폴더를 함께 보관하세요. macOS는 ZIP을 풀고 앱을 응용 프로그램 폴더로 옮깁니다.
  2. Windows는 기본 웹 브라우저에, macOS는 앱 창에 검색 화면이 열립니다.
  3. Windows 제품, 기준일, 종료일을 선택하고 업데이트를 조회합니다. 검색어에 릴리스나 아키텍처를 입력하거나 KB 번호로 찾을 수 있습니다. 목록에 없는 제품은 Microsoft 카탈로그 직접 검색을 선택하세요.
  4. 업데이트를 선택하고 선택 항목 파일 확인을 누릅니다.
  5. 선행·권장 패치도 함께 다운로드 체크박스로 포함 여부를 정합니다.
  6. 저장 폴더를 정하고 다운로드합니다.

인터넷 연결이 필요하며 파일은 실행 중인 컴퓨터에 저장됩니다. 대상 컴퓨터의 설치 상태와 공식 KB 문서를 확인한 뒤 설치 순서를 결정하세요. Windows 실행 파일의 실제 Windows 데스크톱 실행 확인은 남아 있습니다.

지원 환경과 확인된 테스트 범위가 궁금해요.

macOS 앱은 Apple Silicon용입니다. Windows 앱은 x64용입니다. KJ 도구함 Windows 통합판은 Windows 11에서 설치·업데이트·삭제·데이터 보존, 7일 체험·라이선스 검사와 오피스 편집·저장·재열기·PDF 출력을 확인했습니다. 한글의 한국어 입력·HWP 저장·재열기도 확인했습니다. Windows 10과 다른 실물 PC의 검증은 남아 있습니다.

KJ 도구함 Mac 통합판은 macOS 26 이상·Apple Silicon용이며 Intel Mac은 지원하지 않습니다. PDF·이미지·HWP·DOCX·XLSX·PPTX 편집과 저장·재열기, PDF 출력 및 인증 해제·복원을 확인했습니다. 실제 한국어 키보드 조합 입력과 실물 프린터 출력은 별도 확인이 필요합니다. PDF 인쇄창의 전체 페이지 수 문구가 1로 표시될 수 있지만 실제 두 페이지 PDF 출력은 확인했습니다.

macOS 앱은 로컬 서명 앱이며 Developer ID 서명·Apple 공증은 포함되지 않아 처음 실행 시 보안 경고가 표시될 수 있습니다. KJ Patch Downloader의 지원 환경은 해당 다운로드 안내를 확인하세요.

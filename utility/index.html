사용 안내

KJ 도구함은 어떻게 시작하나요?

ZIP 전체를 압축 해제한 뒤 Windows는 KJ Toolbox.exe, macOS는 KJ Toolbox.app을 실행하세요. Windows는 Runtime·App·Data 등 동봉 폴더가 함께 필요합니다.

분류와 도구를 고르고 파일을 추가한 뒤 결과를 저장할 폴더를 선택하세요. Windows 버전은 처음 실행한 시점부터 7일간 체험할 수 있으며, 이후 앱에 표시되는 PC 코드로 발급받은 인증 키를 입력합니다.

패치 다운로더는 어떻게 사용하나요?
  1. ZIP을 풀고 KJ Patch Downloader를 실행합니다. 기본 브라우저에 화면이 열립니다.
  2. 대상 서버, 기준일, 종료일을 선택하고 업데이트를 조회합니다.
  3. 업데이트를 선택하고 선택 항목 파일 확인을 누릅니다.
  4. 선행·권장 패치도 함께 다운로드 체크박스로 포함 여부를 정합니다.
  5. 저장 폴더를 정하고 다운로드합니다. 끝나면 화면의 앱 종료를 누릅니다.

인터넷 연결이 필요하며 파일은 실행 중인 컴퓨터에 저장됩니다. 대상 서버의 설치 상태와 공식 KB 문서를 확인한 뒤 설치 순서를 결정하세요.

지원 환경과 확인된 테스트 범위가 궁금해요.

패치 다운로더는 macOS에서 네 서버 버전의 실제 조회, 체크포인트 식별, 공식 CAB 다운로드와 해시 검증을 확인했습니다. Windows 실행 파일은 교차 빌드했으며 실제 Windows 데스크톱 검증은 진행 전입니다.

macOS 앱은 Apple Silicon용 로컬 서명 앱입니다. Developer ID 공증은 포함되지 않습니다. 프로그램별 상세 조건은 압축 파일 안의 사용 안내에서 확인할 수 있습니다.

오류가 생기거나 새 버전을 찾고 싶어요.

사용한 운영체제, 프로그램 이름·버전, 재현 순서와 오류 문구를 함께 남겨 주세요.
